# SELY.TR MiniGame Hub

SELY.TR; günlük oynanabilir setler, kişisel ustalık rotaları ve erişilebilir kontroller etrafında kurulan özgün bir tarayıcı mini oyun hub’ıdır. Görsel dil; editoryal poster tasarımı, kâğıt yüzeyleri ve baskı atölyesi ritminden oluşur.

## Oyunlar

| Oyun | Kısa açıklama |
|---|---|
| Yankı Odası | Yankı darbeleriyle açılan odada izleri, mührü ve çıkışı bul. |
| Düğüm | Dönen karoları bağlayarak akışı hedefe ulaştır. |
| Kırpık | Sınırlı kesim enerjisiyle kâğıt katmanlarını temizle. |
| Gölge Payı | Gecikmeli gölge rotasıyla iki konumu eşleştir. |
| İşaretçi | Kısa mantık ipuçlarından doğru arşiv hedefini seç. |
| Hane | Sayı ve mantık kurallarını takip ederek doğru haneyi bul. |
| Kıvılcım | Baskı koridorunda planörü yönlendirip ritmi koru. |

## Başlatma

```bash
pnpm install
pnpm dev
```

## Kontrol

```bash
pnpm check
pnpm test
pnpm build
```

## Public / production sınırı

Production ortam değişkenleri, gerçek iletişim bilgileri, arama motoru doğrulama dosyaları ve ajana özel çalışma notları bu depoda bulunmaz.
